# 등기체크

> 등기부등본의 근저당·가압류 항목을 체크리스트 규칙으로 점검해 계약 직전 위험 신호를 쉬운 말로 알려 주는 웹 도구.

## 문제

처음 계약하는 사회초년생이 계약 직전 등기부등본의 근저당·가압류 항목을 봐도 위험한지 판단하지 못해 막힌다.

## 어떻게 동작하나

1. 인터넷등기소에서 열람한 등기부등본 글을 통째로 붙여 넣고 보증금과 시세(대략)를 적는다 — 근저당·가압류·소유자 같은 항목은 자동으로 뽑고, 사람이 보고 고칠 수 있다. 글은 기기 밖으로 안 나간다
2. 미리 정의한 체크리스트 규칙엔진이 항목별 규칙(가압류 존재, 채권최고액과 보증금 합계의 시세 대비 비율, 소유자 불일치 등)을 순서대로 평가해 위험·주의·양호로 분류한다.
3. 항목별 신호등 결과, 그렇게 판단한 이유를 쉬운 말로 풀어쓴 문장, 계약 전 확인할 행동 목록(예: 중개사에게 물어볼 질문)을 한 화면에 보여 준다.

## 실행

```sh
# (만들면서 채우기)
```

## 데모

샘플 등기부등본 글을 붙여 넣으면 을구의 근저당(채권최고액 9천만 원)과 소유자가 뽑혀 나오고, 보증금 1억·시세 1억 5천만을 넣고 '확인'을 누르면 '선순위 9천만 + 보증금 1억 = 시세의 127% — 빨강'과 그 이유, 중개사에게 물어볼 질문이 뜬다
