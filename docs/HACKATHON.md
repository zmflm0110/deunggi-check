# 등기체크 — 해커톤 진행표

## 1. 서류 전형 — 신청서 초안

| 항목 | 초안 |
|---|---|
| 작품명 | 등기체크 |
| 한 줄 소개 | 등기부등본의 근저당·가압류 항목을 체크리스트 규칙으로 점검해 계약 직전 위험 신호를 쉬운 말로 알려 주는 웹 도구. |
| 문제 정의 | 처음 계약하는 사회초년생이 계약 직전 등기부등본의 근저당·가압류 항목을 봐도 위험한지 판단하지 못해 막힌다. |
| 해결 방법 | 등기부등본 글을 붙여 넣고 보증금·시세를 적는다(항목은 자동으로 뽑고 사람이 고친다) → 체크리스트 규칙엔진이 항목별로 위험·주의·양호를 매긴다 → 신호등·쉬운 말 이유·중개사에게 물어볼 질문을 한 화면에 |
| 차별점 | 세이프홈즈·안심전세 앱처럼 등기부를 진단하는 서비스는 이미 있다. 등기체크는 계정·업로드 없이 브라우저 안에서만 돌고(글이 기기 밖으로 안 나감), 판단 규칙이 파일 한 장으로 다 보인다 |
| 사용 기술 | 체크리스트 규칙엔진 |
| 기대 효과 | (누가 무엇을 얼마나 덜 하게 되나 — 지어낸 숫자 말고 근거 있는 것만) |
| 팀 구성·역할 | (이름=역할) |

## 2. 본선 — 일정과 체크포인트

대회 24시간 기준(시작을 0시로).

| 시간 | 단계 | 이때까지 돌아가야 할 것 |
|---|---|---|
| 0–5.4h | 규칙 설계 | 근저당·가압류·소유자 일치 등 점검 항목과 위험 판정 규칙을 체크리스트로 정리; 각 규칙의 쉬운 말 설명과 권장 행동 문구 작성; 규칙을 JSON 데이터로 정의해 코드와 분리 |
| 5.4–11.7h | 규칙엔진 구현 | 입력값을 받아 규칙을 평가하고 위험·주의·양호를 내는 엔진 구현; 규칙별 단위 테스트와 가상의 예시 케이스 3개로 검증 |
| 11.7–18h | 화면 제작 | 등기 정보 입력 폼과 용어 도움말 툴팁 제작; 신호등 결과, 이유, 행동 목록 결과 화면 제작; 모바일 화면 대응 |
| 18–21.6h | 다듬기와 발표 준비 | 데모용 가상 등기 시나리오 2개 준비; 문구 다듬기와 면책 안내 추가; 30초 데모 리허설 |
| 21.6–24h | 제출 준비 | README·영상·발표 자료 최종; 저장소 정리·실행 확인 |

체크포인트마다 5분: 지금 데모 장면이 어디까지 되나, 막힌 건 단순하게 바꿀 수 있나.

## 3. 발표 — 3분

1. 문제(30초) — 한 사람의 장면으로. 숫자는 출처 있는 것만
2. 해결(20초) — 등기부등본의 근저당·가압류 항목을 체크리스트 규칙으로 점검해 계약 직전 위험 신호를 쉬운 말로 알려 주는 웹 도구.
3. 데모(90초) — 샘플 등기부등본 글을 붙여 넣으면 을구의 근저당(채권최고액 9천만 원)과 소유자가 뽑혀 나오고, 보증금 1억·시세 1억 5천만을 넣고 '확인'을 누르면 '선순위 9천만 + 보증금 1억 = 시세의 127% — 빨강'과 그 이유, 중개사에게 물어볼 질문이 뜬다
4. 기술(20초) — 체크리스트 규칙엔진
5. 다음 단계(20초) — 대회 뒤 무엇을 더 하면 진짜로 쓰이나
